# 油枪示值复核与短溢回执台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia（不增加额外依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在「油品价格维护」基础上扩展为调价后的计量核验闭环，数据默认保存在浏览器 localStorage 中。

## 业务闭环

1. **调价下发**：每批调价下发后按油枪生成核验项，登记枪号、班组、油枪示值、计量罐读数和检定有效期。
2. **规则判定（整批停在待复核并保留输入）**：
   - 同枪同班只能一条；
   - 检定有效期不得早于今日；
   - 示值相对偏差 `|示值 − 计量罐读数| / 计量罐读数` 不得超过 **千分之三（±3‰）**。
3. **班组回执**：回填每条枪的补差量（正为短量补收、负为溢余退回）、责任类型和说明。
4. **价格闸门**：未收回全部回执前，或仍存在任一规则冲突时，新挂牌价不得启用，原价继续生效。
5. **冻结留档**：核验完成后冻结批次、枪项与回执，冻结后只读。
6. **更正版本**：冻结数据只能通过「更正」另建带原因的新版本，重新逐枪核验；旧版本沿版本链留档。
7. **刷新一致**：批次、枪项、回执与版本关系持久化到 localStorage，刷新后一一对应；冲突清单跨批次摊平，列出批次、枪号、偏差和命中规则。

## 分层（数据 / 判定 / 存储 / 页面分开）

- `src/domain/types.ts`：领域数据类型（批次、油枪项、回执、挂牌价）。
- `src/domain/rules.ts`：判定层，纯函数（偏差计算、同枪同班判重、检定期、3‰、冻结检查）。
- `src/domain/storage.ts`：存储层，localStorage 读写、版本兼容与种子数据。
- `src/stores/verification.ts`：Pinia 状态层，编排动作并拦截对冻结批次的写入。
- `src/components/*`、`src/App.vue`：页面层，只负责展示与交互。
